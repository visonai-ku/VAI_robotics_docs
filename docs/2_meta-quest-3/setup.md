# Meta Quest 3 초기 설정 및 사용법

:::note
기기를 처음 받았을 때의 설정과, 세션마다 반복하게 되는 기본 사용법입니다.
항목별 공식 안내는 [Meta Quest 3 시작하기](https://www.meta.com/ko-kr/help/quest/1994971530885728/)에 정리되어 있습니다.
:::

## 준비물

- **계정**: Meta 계정 (헤드셋 최초 설정 시 필요)
- **앱**: 스마트폰의 Meta Horizon 앱 (페어링·Wi-Fi 설정에 사용)
- **케이블**: USB-C 충전 케이블
- **네트워크**: 로봇 네트워크 Wi-Fi `AIWORKER1115` (PW: `AIWORKER1115`)

## 1. 기기 최초 설정

1. 상자 구성품을 확인합니다. (헤드셋, Touch Plus 컨트롤러 2개, AA 배터리, 충전기, 안경 스페이서)
2. 헤드셋을 충전한 뒤 전원 버튼으로 켭니다.
3. 스마트폰 Meta Horizon 앱으로 헤드셋을 페어링하고 Meta 계정에 로그인합니다.
4. 안내에 따라 **경계(가드레인)** 를 설정합니다. 텔레옵은 제자리에서 하므로 좁은 고정 경계로 충분하지만, 팔을 크게 움직이므로 주변에 장애물이 없어야 합니다.

## 2. 착용 조정

- 좌우 스트랩과 상단 스트랩을 조여 헤드셋이 흔들리지 않게 합니다.
- 렌즈 간 거리(IPD)를 조절해 화면이 가장 선명한 위치를 찾습니다.
- 안경을 쓴다면 동봉된 **안경 스페이서**를 끼웁니다.
- 얼굴에 닿는 **안면 인터페이스**는 분리해서 닦을 수 있습니다. 여러 명이 돌아가며 쓰는 장비이므로 세션 후 닦아 두세요.

## 3. 충전과 상태 표시등

| 표시등 | 상태 |
| --- | --- |
| 주황색 | 충전 중 |
| 초록색 | 충전 완료 |
| 빨간색 | 배터리 매우 부족 |

- 텔레옵 세션은 배터리를 빠르게 소모합니다. 긴 데이터 수집 전에는 **충전기를 연결한 채** 사용하는 편이 안전합니다.
- 컨트롤러는 AA 배터리를 사용합니다. 여분을 준비해 두세요.

## 4. Wi-Fi 연결 (팀 필수 설정)

텔레옵을 하려면 Quest·맥북·로봇이 **모두 같은 네트워크(192.168.6.x)** 에 있어야 합니다.

1. 헤드셋에서 **설정 → Wi-Fi** 로 이동합니다.
2. `AIWORKER1115` 를 선택하고 비밀번호 `AIWORKER1115` 를 입력합니다.
3. 연결 후 IP가 `192.168.6.x` 대역인지 확인합니다.

:::tip
QR 코드로도 Wi-Fi를 연결할 수 있습니다. 비밀번호 입력이 번거로울 때 유용합니다.
:::

## 5. 브라우저로 텔레옵 페이지 접속

1. 헤드셋에서 **브라우저**를 엽니다.
2. 주소창에 직접 입력합니다: `https://192.168.6.xxx:8443/`
   - `https://` 와 `:8443` 이 모두 필요합니다.
   - 방문 기록에 남은 **다른 IP를 누르지 마세요.** 맥북 IP는 DHCP라 바뀝니다.
3. "연결이 비공개로 설정되어 있지 않습니다" 경고가 뜨면 **고급 → 계속 진행** 을 누릅니다. (자체 서명 인증서라 정상입니다)
4. "Fixed Quest" 페이지 맨 위의 **[Quest에서 XR 시작]** 버튼을 누릅니다.
5. VR 화면에 들어가면 양손 컨트롤러를 듭니다.

:::warning[탭은 하나만]
Quest 브라우저에 텔레옵 탭이 여러 개 열려 있으면 입력이 들어오지 않습니다. 탭 하나만 남기고 XR을 시작하세요.
:::

## 6. 알아 두면 좋은 기능

- **패스스루**: 헤드셋을 벗지 않고 바깥을 볼 수 있습니다. 로봇 상태를 눈으로 확인할 때 유용합니다.
- **Meta 버튼**: 누르면 VR이 일시정지됩니다. 텔레옵 중에는 누르지 마세요.
- **재시작**: 전원 버튼을 길게 눌러 재시작을 선택합니다. 트래킹이 이상하거나 브라우저가 먹통일 때 가장 빠른 해결책입니다.
- **기록/미러링**: 헤드셋 화면을 녹화하거나 다른 기기로 미러링할 수 있습니다. 시연 영상 촬영에 사용합니다.

## 동작 확인

- Wi-Fi가 `AIWORKER1115` 에 연결되어 있는가
- 브라우저에서 `https://192.168.6.xxx:8443/` 페이지가 열리는가
- XR 시작 후 양손 컨트롤러가 화면에 보이는가
- 맥북 컨트롤 창 상태가 `WAIT_INPUT · no_frame` 이 **아닌가**

## 자주 겪는 문제

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| "사이트에 연결할 수 없음" | 맥북 노트북 셀이 안 돌고 있거나 IP가 틀림 | 셀 실행 후 설정 셀이 알려준 IP로 접속 |
| 컨트롤 창 `WAIT_INPUT · no_frame` | XR 시작 미실행, 맨손 사용, 탭 여러 개 | 탭 하나만 두고 XR 시작, 컨트롤러 들기 |
| `tracking_lost_left/right` | 컨트롤러가 꺼졌거나 헤드셋 시야 밖 | 컨트롤러를 시야 안으로, 배터리 확인 |
| 인증서 경고가 계속 뜸 | 자체 서명 인증서 | **고급 → 계속 진행** (정상) |
| 화면이 흐림 | IPD·착용 위치 | 렌즈 간 거리와 스트랩 재조정 |
| 경계 경고가 계속 뜸 | 가드레인이 좁게 잡힘 | 경계를 다시 설정하거나 고정 경계로 전환 |
